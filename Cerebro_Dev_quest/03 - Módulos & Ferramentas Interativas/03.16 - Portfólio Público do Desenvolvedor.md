# 🌐 Portfólio Público do Desenvolvedor (`/u/[username]`)

> [!abstract] Resumo Executivo
> O **Portfólio Público** (`/u/[username]`) transforma o esforço diário do estudante no DevQuest em uma página de apresentação profissional pronta para ser compartilhada com recrutadores, no LinkedIn ou no currículo. Ele reúne biografia, links sociais, **Matriz de Competências Técnicas**, badges desbloqueadas, projetos práticos validados no GitHub e o **Heatmap Anual de Atividade**.

---

## 💼 Por que um Portfólio Público Integrado?

Em processos seletivos de tecnologia, recrutadores e Tech Leads buscam **provas de trabalho reais** (*Proof of Work*), e não apenas diplomas teóricos. A página de portfólio do DevQuest sintetiza:
1. **Consistência Comprovada**: O Heatmap de atividade anual demonstra disciplina e hábito contínuo.
2. **Habilidades Mensuradas**: Barras de proficiência em TypeScript, React 19, Estruturas de Dados, SQL e CSS.
3. **Projetos Auditáveis**: Links diretos para os repositórios GitHub e para as especificações no DevQuest.
4. **Badges de Conquistas**: Prova de superação de testes técnicos de empresas reais (ex: aprovação no simulador do Nubank).

## 🏗️ Arquitetura e Implementação Técnica

* **Localização do Código**:
  * Componente do Portfólio: `src/components/profile/PublicPortfolioView.tsx`
  * Rota Dinâmica Next.js 16: `src/app/u/[username]/page.tsx`
  * Rota do Heatmap Integrada: `src/components/daily/ActivityHeatmap.tsx`

### 1. Parâmetros Assíncronos no Next.js 16
No Next.js 15+, os parâmetros de rota dinâmica (`params`) são tratados como `Promise` para otimização de streaming e SSR:

```typescript
interface PublicProfilePageProps {
  params: Promise<{ username: string }>;
}

export async function generateMetadata({ params }: PublicProfilePageProps): Promise<Metadata> {
  const { username } = await params;
  const decodedUsername = decodeURIComponent(username);
  return {
    title: `Portfólio de @${decodedUsername} | DevQuest Pro`,
    description: `Confira o perfil técnico e projetos de @${decodedUsername} no DevQuest Pro.`,
  };
}

export default async function PublicProfilePage({ params }: PublicProfilePageProps) {
  const { username } = await params;
  const decodedUsername = decodeURIComponent(username);
  return <PublicPortfolioView username={decodedUsername} />;
}
```

### 2. Seções do Portfólio
* **Header de Destaque**: Avatar, nome, username, bio, selo `DEV PRO`, botão de copiar link e atalho para verificação de certificado oficial.
* **Cards de Métricas**: Pontuação Total XP, Liga Semanal (Diamante, Ouro, etc.), Sequência Ativa (🔥 Streaks) e Desafios Resolvidos.
* **Heatmap Anual**: Grade de 150+ dias com os 5 níveis de atividade.
* **Matriz de Competências**: Barras com gradiente neon para cada stack tecnológica.
* **Vitrine de Projetos**: Cards com descrição, link para o código-fonte no GitHub e página de especificação interna.
