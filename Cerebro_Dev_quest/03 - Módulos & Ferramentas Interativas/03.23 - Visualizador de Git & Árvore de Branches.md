# 🌳 Visualizador de Git & Árvore de Branches (`/git-visualizer`)

O **Git Visualizer** é um laboratório interativo inspirado no clássico *LearnGitBranching*, projetado para desmistificar conceitos fundamentais e intermediários de controle de versão (commits, ponteiros de branches, detached HEAD, merge fast-forward vs 3-way, e rebase linear) por meio de um terminal CLI emulado e um grafo animado em SVG puro.

---

## 🎯 Arquitetura e Engenharia

### 1. Motor Git em Memória (`src/lib/git/gitEngine.ts`)
* **Estrutura de Dados do Grafo**:
  - `commits: GitCommit[]`: Lista de nós contendo `id` (hash determinístico `c0`, `c1`...), `message`, `parentIds` (múltiplos pais suportados para merge commits), `branchName` e `timestamp`.
  - `branches: Record<string, string>`: Dicionário relacionando o nome do ramo ao ID do commit apontado.
  - `head: GitHead`: Objeto indicando se o ponteiro ativo está associado a uma branch (`type: "branch"`, `name: "main"`) ou desanexado diretamente em um commit específico (`type: "detached"`, `name: "c0"`).
* **Comandos Suportados**:
  - `git commit [-m "mensagem"]`: Cria novo nó com `parentIds: [currentCommit]` e avança o ponteiro da branch ativa.
  - `git branch <nome>` / `git branch -d <nome>`: Criação e remoção de ponteiros de branches.
  - `git checkout <branch|hash>` / `git switch <branch>`: Navegação entre branches ou detached HEAD.
  - `git checkout -b <nome>` / `git switch -c <nome>`: Criação atômica com troca de branch.
  - `git merge <branch>`: Detecta automaticamente se é possível realizar *fast-forward* (quando o commit alvo é ancestral linear) ou se deve gerar um *merge commit* com 2 nós pais.
  - `git rebase <alvo>`: Localiza os commits exclusivos da branch ativa e os reaplica linearmente no topo do commit da branch alvo.
  - `git reset --hard <hash|HEAD~1>`: Retrocede ponteiros de commits.
  - `git log`, `git status`, `git help`, `clear`.

### 2. Grafo Visual Reativo em SVG Puro
* Renderização matemática direta via curvas de Bézier cúbicas (`M x1 y1 C ...`) ligando nós pais a nós filhos sem dependências externas pesadas (como D3 ou Cytoscape).
* Badges de branches renderizadas flutuando sobre os nós apontados, com destaque pulsante no nó de `HEAD`.
* Zoom interativo (60% a 180%) e reset de perspectiva.

## 🎮 Missões Pedagógicas Guiadas (`src/lib/data/gitMissions.ts`)
1. **Missão 1**: *O Primeiro Commit* (criação do primeiro snapshot de código).
2. **Missão 2**: *Criando sua Primeira Branch* (desenvolvimento isolado).
3. **Missão 3**: *Trabalhando em Paralelo* (commit em feature e retorno para a main).
4. **Missão 4**: *Integrando com Git Merge* (unindo o histórico da feature na main).
5. **Missão 5**: *Histórico Linear com Git Rebase* (reaplicação de commits na ponta da árvore).
6. **Missão 6**: *Viagem no Tempo e Detached HEAD* (inspeção de commits antigos).
