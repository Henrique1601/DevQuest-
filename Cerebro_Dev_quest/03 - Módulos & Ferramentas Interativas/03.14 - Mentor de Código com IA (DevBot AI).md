# 🤖 Mentor de Código com IA (DevBot AI Mentor)

> [!abstract] Resumo Executivo
> O **DevBot AI Mentor** é o assistente inteligente integrado diretamente ao `ChallengeWorkspace` da Arena de Desafios. Ele segue a metodologia **socrática**: em vez de entregar o código pronto e privar o estudante do aprendizado, ele guia o raciocínio por meio de perguntas reflexivas, dicas graduais, análise de complexidade assintótica e inspeção de armadilhas clássicas (loops infinitos, mutabilidade e retornos ausentes).

---

## 💡 Filosofia Pedagógica: Abordagem Socrática

Modelos generativos comuns tendem a cuspir a resposta completa, criando o chamado "vício da solução pronta". O DevBot AI opera sob regras estritas:
1. **Nunca entregar a resposta de bandeja**: Perguntar qual caso de borda (*edge case*) pode estar quebrando.
2. **Dicas em Camadas**: O estudante pode pedir `Dica Leve`, `Dica Intermediária` ou `Explicar Complexidade Big-O`.
3. **Análise Estática Heurística**: Identificação em tempo real no código escrito de:
   * Falta de cláusula `return`
   * Mutações acidentais de parâmetros
   * Loops aninhados $O(n^2)$ que podem sofrer Time Limit Exceeded (TLE)
   * Potenciais recursões sem caso-base

## 🏗️ Arquitetura e Implementação Técnica

* **Localização do Código**:
  * Motor heurístico & prompts: `src/lib/ai/mentor.ts`
  * Interface gráfica: `src/components/ai/DevBotMentor.tsx`
  * Integração com workspace: `src/components/challenges/ChallengeWorkspace.tsx`
  * Testes Unitários: `src/__tests__/mentor.test.ts`

### Interface de Tipos do Mentor
```typescript
export interface MentorHintRequest {
  code: string;
  challengeTitle: string;
  language: "javascript" | "typescript" | "python";
  failedTestError?: string;
}

export interface MentorAnalysis {
  status: "idle" | "analyzing" | "ready";
  socraticQuestion: string;
  complexityInsight: string;
  syntaxWarning?: string;
  hintLevel: 1 | 2 | 3;
}
```

### Motor de Regras e Análise
O arquivo `src/lib/ai/mentor.ts` analisa o código do usuário:
* Se detectar loops aninhados com `for` ou `while`, avisa sobre a penalidade de desempenho de tempo quadrático ($O(n^2)$) e sugere o uso de tabelas hash / mapas (`Map`, `Set`, dicionários).
* Se os testes falharem com erro de execução (`undefined`, `TypeError`), diagnostica se o retorno foi esquecido ou se houve acesso a propriedades de nulo.
* Permite conexão extensível com endpoints LLM externos (Google Gemini Flash, Anthropic Claude ou OpenAI) caso chaves de API estejam configuradas.

## 🧪 Testes Automatizados
O arquivo `src/__tests__/mentor.test.ts` verifica:
* Detecção de complexidade quadrática em laços aninhados.
* Diagnóstico de funções sem retorno.
* Geração progressiva de dicas socráticas por nível de ajuda.
