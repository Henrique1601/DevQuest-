# 🔍 Code Review Automatizado com IA (Estilo Pull Request)

> [!abstract] Resumo Executivo
> O módulo **Code Review com IA** (`/code-review`) simula o processo formal de revisão de código de times de alta performance e projetos open source no GitHub. A ferramenta analisa qualquer trecho de código submetido, emite um veredito oficial (`APPROVED`, `CHANGES_REQUESTED` ou `COMMENT`), gera uma **pontuação de qualidade (0 a 100)** e exibe **comentários inline por linha** e um **visualizador de Diff lado a lado (`git diff`)** com sugestões seguras de refatoração.

---

## 🎯 Por que Simular Pull Requests Reais?

Em processos seletivos e no dia a dia corporativo, a aprovação de uma feature depende de code reviews criteriosos. O DevBot PR Inspector avalia três pilares fundamentais:
1. **Segurança Defensiva (OWASP Top 10)**:
   - Identificação de SQL Injection por concatenação (`CWE-89`).
   - Riscos de XSS através de `innerHTML` sem sanitização.
   - Execução remota perigosa (`eval`, `new Function`).
   - Vazamento acidental de segredos (chaves de API hardcoded).
2. **Clean Code & Arquitetura**:
   - Detecção de mutação direta de parâmetros (`splice`, `length = 0`).
   - Tratamento de exceção silencioso (*empty catch blocks*).
   - Uso de declarações legadas (`var` ao invés de `const`/`let`).
3. **Desempenho & Hooks Modernos**:
   - Detecção de **Memory Leaks** no React (falta de desinscrição/cleanup em `useEffect` com listeners ou `setInterval`).
   - Complexidade quadrática $O(n^2)$ em buscas e laços aninhados.

## 🏗️ Arquitetura e Implementação Técnica

* **Localização do Código**:
  * Engine de Análise Estática: `src/lib/ai/codeReview.ts`
  * Interface Gráfica do Workspace: `src/components/review/CodeReviewWorkspace.tsx`
  * Rota Next.js: `src/app/code-review/page.tsx`
  * Integração na Arena de Desafios: `src/components/challenges/ChallengeWorkspace.tsx`
  * Testes Unitários: `src/__tests__/code-review.test.ts`

### 1. Interface do Resultado da Revisão
```typescript
export type ReviewVerdict = "APPROVED" | "CHANGES_REQUESTED" | "COMMENT";

export interface CodeReviewResult {
  score: number;
  verdict: ReviewVerdict;
  summary: string;
  comments: InlineComment[];
  refactoredCode: string;
  metrics: {
    securityScore: number;
    maintainabilityScore: number;
    performanceScore: number;
  };
}
```

### 2. Modos de Visualização
* **Pull Request Inline**: Renderiza cada linha de código com balões expansíveis de feedback contendo severidade (`critical`, `warning`, `suggestion`), explicação didática e código sugerido pronto para cópia.
* **Split Diff**: Comparador visual com o código original destacado em vermelho (`-`) e a refatoração sugerida destacada em verde (`+`).
* **Editor Customizado**: Permite ao desenvolvedor colar seu próprio código ou escolher presets pré-configurados.

## 🧪 Testes Automatizados
O arquivo `src/__tests__/code-review.test.ts` valida:
* Presets com casos de teste reais.
* Detecção mandatória de SQL Injection com bloqueio `CHANGES_REQUESTED`.
* Identificação de memory leaks em hooks React.
* Cálculo de pontuação e aprovação com louvor de códigos limpos.
