# 🎨 Desafios de UI/UX Pixel-Perfect (Estilo Frontend Mentor)

> [!abstract] Resumo Executivo
> A seção **Frontend Pixel-Perfect** (`/ui-challenges`) preenche a lacuna deixada por plataformas tradicionais de código puro (como LeetCode), que ignoram completamente estilização, fidelidade visual e responsividade. O aluno recebe o protótipo de design de referência e um editor de código HTML/CSS, podendo arrastar uma **barra divisória interativa (Split Slider)** para comparar sua reprodução milímetro a milímetro com o design original.

---

## 🎯 Por que Desafios Visuais?

No mercado real de engenharia de software, desenvolvedores frontend gastam mais de 70% do tempo transformando layouts do Figma em interfaces de alta fidelidade acessíveis, fluidas e responsivas. O módulo avalia:
* Uso de CSS Grid e Flexbox moderno.
* Glassmorphism, sombras realistas (`box-shadow`), gradientes e transições.
* Efeitos de foco, estados de hover e tipografia escalável.

### 1. Mecanismo do Slider Comparador (Split View)
O componente calcula o ponto de corte percentual (`sliderPos` de 0% a 100%) conforme o cursor do mouse ou toque na tela é arrastado:

```tsx
<div className="relative w-full h-[520px] rounded-2xl overflow-hidden border border-surface-border">
  {/* Camada Inferior: Design Original de Referência */}
  <div className="absolute inset-0 bg-[#080B11] flex items-center justify-center">
    <div dangerouslySetInnerHTML={{ __html: challenge.targetHtml }} />
  </div>

  {/* Camada Superior: Código do Aluno (Clip-Path Dinâmico) */}
  <div
    className="absolute inset-0 bg-[#080B11] flex items-center justify-center pointer-events-none"
    style={{ clipPath: `inset(0 ${100 - sliderPos}% 0 0)` }}
  >
    <div dangerouslySetInnerHTML={{ __html: userCode }} />
  </div>

  {/* Linha Divisória com Alça Arrastável */}
  <div
    className="absolute top-0 bottom-0 w-1 bg-cyan-400 cursor-ew-resize z-20 shadow-glow"
    style={{ left: `${sliderPos}%` }}
  >
    <div className="absolute top-1/2 -translate-y-1/2 -translate-x-1/2 w-8 h-8 rounded-full bg-cyan-500 text-black flex items-center justify-center font-bold">
      ⇄
    </div>
  </div>
</div>
```

### 2. Desafios Iniciais Disponíveis
1. **Cartão de Crédito Glassmorphic**:
   * Efeito `backdrop-blur-md`, bordas semi-transparentes, chip dourado, bandeira do cartão e numeração estilizada.
2. **Pricing Card Switcher**:
   * Alternador Mensal/Anual com desconto, destaque de plano popular e layout em cartões contrastantes.
