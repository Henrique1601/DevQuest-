# ⚔️ Arena de Desafios & Code Runner

> [!abstract] Resolução de Problemas no Estilo LeetCode
> A rota `/challenges` é o núcleo de prática diária do DevQuest, oferecendo dezenas de problemas algorítmicos organizados por tópicos (Arrays, Strings, Hash Maps, Recursão, Algoritmos).

---

## 💻 Como Funciona a Execução Segura no Navegador

O test runner do DevQuest avalia as soluções no cliente sem latência de rede:

1. O usuário edita o código no **CodeMirror 6** com autocomplete e realce de sintaxe.
2. Ao clicar em **"Submeter Resposta"**, o componente monta um wrapper dinâmico:
   ```javascript
   const runner = new Function(`
     ${userCode}
     return typeof ${functionName} !== 'undefined' ? ${functionName} : null;
   `)();
   ```
3. O runner itera sobre os `test_cases` cadastrados no banco ou no dataset estático, comparando a saída `actual` com `expected` via serialização profunda.
4. Se todos os testes passarem:
   - Dispara efeito de confete visual.
   - Envia requisição para a API `/api/challenges` para registrar a submissão e creditar XP ao usuário.
