# 💼 Ferramentas de Carreira & Portfólio do Desenvolvedor

Este módulo reúne utilitários criados para transformar o progresso dos alunos dentro da plataforma em ativos reais para empregabilidade, visibilidade em redes profissionais (LinkedIn/X) e documentação de alto nível para repositórios GitHub.

---

## 1. Gerador de README.md Profissional para Projetos Guiados (`/projects/[slug]`)

* **Localização**: Componente `ProjectReadmeButton` e modal `ProjectReadmeModal` via React Portal no `document.body` com `z-[9999]`.
* **Geração Automatizada de Markdown**:
  - **Badges Oficiais Shields.io**: Status do projeto (concluído), dificuldade, licença MIT e logos oficiais das tecnologias utilizadas (Next.js, React, Tailwind, TypeScript, etc.).
  - **Checklist de Features**: Listagem estruturada com caixas de seleção marcadas (`[x]`) das especificações implementadas.
  - **Arquitetura de Diretórios**: Visualização da árvore de pastas recomendada.
  - **Guia Passo a Passo de Execução**: Comandos de clonagem (`git clone`), instalação (`npm install`) e inicialização local (`npm run dev`).
  - **Identidade do Autor**: Campos editáveis para nome e GitHub do aluno com geração de links automáticos.
* **Ergonomia e Exportação**:
  - Alternador instantâneo entre **Preview Renderizado** e **Código Markdown Cru**.
  - Botão de **Copiar Markdown** (com som harmônico e toast).
  - Botão de **Download Direto de Arquivo** (`README-<slug>.md`).

---

## 2. Card Social de Conquistas em Alta Resolução 1200x630 (`/profile`)

* **Localização**: Componente `SocialShareCardModal` na página `/profile`.
* **Renderização Nativa via HTML5 Canvas**:
  - Resolução oficial OpenGraph de **1200x630 pixels** (proporção 1.91:1 recomendada para LinkedIn, Twitter/X, Discord e WhatsApp).
  - Estética Dark Cyberpunk com iluminação radial neon (ciano e roxo) e malha de pontos sutis.
  - Exibição de Avatar circular com anel gradiente, Nome do Desenvolvedor, Nível e Selo "✓ VERIFIED DEVELOPER".
  - **4 Cards de Métricas Glassmorphism**:
    1. Experiência Total (`totalXp` XP).
    2. Desafios Vencidos (algoritmos aprovados).
    3. Projetos Entregues (aplicações no GitHub).
    4. Ofensiva Contínua (`streakDays` dias seguidos).
  - **Código Hash de Validação**: Hash único baseado no nível e experiência para autenticidade do card.
* **Ações Rápidas**:
  - Download em formato PNG em alta fidelidade.
  - Cópia direta da imagem para a área de transferência do sistema operacional via `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`.
  - Cópia de texto persuasivo pronto para postar no LinkedIn com hashtags estratégicas.
