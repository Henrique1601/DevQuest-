# 💻 Terminal Linux & Missões Git

> [!abstract] Prática de Linha de Comando no Navegador
> Localizado na rota `/terminal`, oferece um emulador de terminal UNIX com árvore de arquivos virtual (*in-memory virtual file system*) e missões interativas para aprender comandos essenciais de terminal e fluxo Git sem risco de danificar a máquina real do aluno.

---

## 🖥️ Comandos Simulados

* **Navegação & Arquivos**: `ls`, `cd`, `pwd`, `cat`, `mkdir`, `touch`, `rm`, `clear`, `help`.
* **Fluxo Git Real**:
  - `git init`
  - `git status`
  - `git add <file>`
  - `git commit -m "msg"`
  - `git branch`, `git checkout`
  - `git log --oneline`

---

## 🎯 Missões Gamificadas
O terminal inclui um sistema de missões com objetivos guiados (ex: *"Missão 1: Inicialize um repositório Git e crie seu primeiro commit com index.html"*). Ao concluir a missão, o terminal solta uma mensagem de sucesso e desbloqueia o próximo desafio.
