# 🩺 Debug Clinic & Snippet Vault

> [!abstract] Ferramentas de Produtividade do Dia a Dia
> Duas seções desenhadas para acelerar a resolução de problemas reais de desenvolvimento:
> 1. **Debug Clinic** (`/debug-clinic`): Biblioteca dos erros mais comuns de JavaScript, React, TypeScript e SQL, explicando a causa raiz e o código de correção.
> 2. **Snippet Vault** (`/snippets`): Coleção de utilitários prontos para copiar e colar em projetos de produção (Hooks React, debounce, formatação de moedas, validadores de CPF/CNPJ).

---

## 🩹 Exemplos no Debug Clinic
* `TypeError: Cannot read properties of undefined (reading 'map')`: Causa e uso de Optional Chaining (`?.`) ou valor default `[]`.
* `Hydration failed because the initial UI does not match the server`: Causa e uso de `useEffect` para flags de cliente.
* `CORS Error: No 'Access-Control-Allow-Origin' header is present`: Causa e configuração de headers no backend.
