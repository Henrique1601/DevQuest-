# 📊 Modelos de Dados & Schemas Drizzle

> [!abstract] Definição de Entidades do Sistema (`src/lib/db/schema.ts`)
> Todas as tabelas são modeladas de forma estrita em TypeScript utilizando o pacote `drizzle-orm/pg-core`.

## 🗃️ Diagrama Entidade-Relacionamento (DER)

```mermaid
erDiagram
    USERS ||--o{ ACCOUNTS : "possui contas oauth"
    USERS ||--o{ SUBMISSIONS : "envia solucoes"
    USERS ||--o{ PROJECT_COMPLETIONS : "completa projetos"
    CHALLENGES ||--o{ SUBMISSIONS : "recebe tentativas"

    USERS {
        uuid id PK
        text name
        text email UK
        text password_hash
        text avatar_url
        integer xp
        integer level
        timestamp created_at
    }

    ACCOUNTS {
        uuid id PK
        uuid user_id FK
        text type
        text provider
        text provider_account_id
        text refresh_token
        text access_token
    }

    CHALLENGES {
        text id PK
        text slug UK
        text title
        text difficulty
        text category
        integer xp
        text description
        text starter_code
        text function_name
        jsonb test_cases
    }

    SUBMISSIONS {
        uuid id PK
        uuid user_id FK
        text challenge_id FK
        text code
        boolean passed
        timestamp executed_at
    }

    PROJECTS {
        text id PK
        text slug UK
        text title
        text tagline
        text difficulty
        text category
        integer estimated_hours
        jsonb tags
        jsonb features
    }

    PROJECT_COMPLETIONS {
        uuid id PK
        uuid user_id FK
        text project_slug
        text github_url
        timestamp completed_at
    }
```

## 📋 Detalhamento dos Campos Críticos

### 1. `challenges`
* `functionName`: O nome da função JavaScript exportada que o test runner invocará.
* `testCases`: JSON estruturado contendo `{ input: any[], expected: any, description: string }`.

### 2. `submissions`
* Registra o código enviado e se o usuário passou em 100% dos testes para fins de pontuação de XP e auditoria.
