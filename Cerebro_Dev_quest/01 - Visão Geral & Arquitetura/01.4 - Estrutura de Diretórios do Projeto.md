# 📂 Estrutura de Diretórios do Projeto

> [!abstract] Mapeamento Completo da Raiz e Subpastas
> O repositório segue a convenção canônica do Next.js App Router, com clara separação entre páginas de roteamento (`src/app`), componentes de UI reutilizáveis (`src/components`), dados estáticos/mocks (`src/lib/data`), banco de dados (`src/lib/db`) e suíte de testes (`src/__tests__`).

---

## 🌳 Árvore de Diretórios

```text
DevQuest-/
├── Cerebro_Dev_quest/               # 🧠 Segundo Cérebro Obsidian (Este Cofre)
│   ├── 00 - MOC/                    # Mapas de Conteúdo Centrais
│   ├── 01 - Visão Geral & Arquitetura/
│   ├── 02 - Banco de Dados & Autenticação/
│   ├── 03 - Módulos & Ferramentas Interativas/
│   ├── 04 - Conteúdo Pedagógico/
│   └── 05 - DevOps, Testes & Operação/
│
├── src/
│   ├── app/                         # 🌐 Next.js App Router (Rotas & Páginas)
│   │   ├── api/                     # Route Handlers de Backend
│   │   │   ├── auth/                # Endpoints NextAuth & Register
│   │   │   ├── challenges/          # Submissão de desafios
│   │   │   └── status/              # Healthcheck do sistema
│   │   ├── certificate/[id]/        # 🎓 Página do Certificado Verificável

│   │   ├── leaderboard/             # 🏆 Ranking Global & Ligas de XP
│   │   ├── login/ & register/       # 🔐 Telas de Login e Cadastro
│   │   ├── playground/              # 🛝 Web Playground HTML/CSS/JS
│   │   ├── profile/                 # 👤 Painel do Desenvolvedor
│   │   ├── projects/[slug]/         # 🛠️ Projetos Práticos Guiados
│   │   ├── snippets/                # ✂️ Snippet Vault
│   │   ├── sql-playground/          # 🗃️ SQL Playground Interativo

│   │

│   │
│   ├── lib/                         # ⚙️ Utilitários, Banco e Dados
│   │   ├── algorithms/              # Geradores de passos para visualizadores
│   │   ├── data/                    # Datasets de métodos, desafios, projetos
│   │   └── db/                      # Conexão Neon, Schemas Drizzle e Seeds
│   │
│   └── __tests__/                   # 🧪 Suíte de Testes Automatizados (Vitest)
│       ├── certificate.test.ts
```
