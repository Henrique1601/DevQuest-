# 🌐 SEO Técnico, Indexação & Badges Dinâmicos para GitHub

> [!abstract] Resumo Executivo
> Esta nota documenta a camada de **Search Engine Optimization (SEO)**, indexação orgânica, metadados semânticos e a **API geradora de Badges SVG para GitHub README** do DevQuest Pro. Com o crescimento contínuo do ecossistema para mais de 47 rotas ativas, essas otimizações asseguram posicionamento de destaque nos mecanismos de busca (Google, Bing) e amplificam o crescimento orgânico através de provas de trabalho compartilháveis.

---

## 🗺️ 1. Mapa do Site Dinâmico (`src/app/sitemap.ts`)

O Next.js gera sob demanda o arquivo `sitemap.xml` agregando todas as entidades do sistema:
* **Rotas Estáticas Globais**: `/`, `/challenges`, `/daily`, `/code-review`, `/ai-lab`, `/ui-challenges`, `/interviews`, `/leaderboard`, `/cheatsheets`, etc. (Prioridade 1.0 a 0.8).
* **Trilhas de Estudo**: Mapeamento das 5 trilhas oficiais (`/tracks/[slug]`) com prioridade 0.85 e atualização semanal.
* **Projetos Guiados**: Mapeamento dos 17 projetos práticos (`/projects/[slug]`) com prioridade 0.80.

---

## 🤖 2. Diretrizes de Rastreamento (`src/app/robots.ts`)

Configuração das permissões para rastreadores web:
* **User-Agent: `*`**: Permite varredura em todo o conteúdo público.
* **Disallow**: Protege rotas internas de autenticação (`/api/auth/`).
* **Sitemap Pointer**: Aponta diretamente para `https://devquest-zeta.vercel.app/sitemap.xml`.

---

## 🏷️ 3. Metadados Canônicos, OpenGraph & Schema.org (JSON-LD)

No arquivo `src/app/layout.tsx`:
* **Canonical URL & metadataBase**: Garante resolução determinística de URLs absolutas em produção.
* **OpenGraph & Twitter Cards**: Pré-visualizações ricas com banners, título e descrição em redes sociais e apps de mensagens (WhatsApp, LinkedIn, Discord).
* **Dados Estruturados JSON-LD**:
  * Tipo `@type: EducationalOrganization`: Classifica o DevQuest como organização educacional no Google Search Console.
  * Tipo `@type: WebSite`: Habilita indexação de busca semântica.

---

## 🛡️ 4. Resiliência de Navegação (404 & Error Boundary)

* **`src/app/not-found.tsx`**: Página 404 customizada com estética cyberpunk, diagnóstico de terminal e atalhos rápidos para a Arena e o Desafio Diário.
* **`src/app/error.tsx`**: Error boundary com captura global de exceções e botão de recuperação em tempo real (`reset()`).

---

## 🚀 5. Badge SVG Dinâmico para o GitHub Profile README (`/api/badge/[username]`)

Para impulsionar a viralidade da plataforma, foi criada a rota de API:
`GET /api/badge/[username]`

### Características Técnicas do SVG:
* **Vetorização Pura**: Renderiza em qualquer resolução (Retina / 4K) sem perda de nitidez.
* **Métricas em Tempo Real**:
  * Pontuação total de XP
  * Ofensiva ativa com emoji de fogo (🔥 18d)
  * Liga atual (💎 Diamante)
  * Total de desafios concluídos
* **Cache Inteligente**: Cabeçalhos HTTP com `Cache-Control: public, max-age=1800, s-maxage=3600` para carregamento instantâneo no GitHub sem sobrecarregar a Vercel.

### Como o Usuário Utiliza:
O estudante acessa `/u/[username]` e clica no botão **"GitHub Badge"**, copiando o seguinte código para o seu perfil:
```markdown
[![DevQuest Stats](https://devquest-zeta.vercel.app/api/badge/henrique_dev)](https://devquest-zeta.vercel.app/u/henrique_dev)
```

O arquivo `src/__tests__/seo-badge.test.ts` valida:
* Existência de todas as rotas esperadas no array do sitemap.
