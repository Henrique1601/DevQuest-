# 🚀 Deploy na Vercel & Variáveis de Ambiente

> [!abstract] Hospedagem & Entrega Contínua
> A aplicação está em produção sob a URL oficial:
> **`https://devquest-zeta.vercel.app/`**
> O fluxo de CI/CD é acionado automaticamente a cada `git push origin main`.

---

## 🔐 Variáveis de Ambiente Obrigatórias (`.env`)

| Variável | Descrição | Exemplo de Valor |
| :--- | :--- | :--- |
| **`DATABASE_URL`** | String de conexão com o banco Neon Serverless PostgreSQL | `postgresql://neondb_owner:***@ep-xyz.us-east-2.aws.neon.tech/neondb?sslmode=require` |
| **`AUTH_SECRET`** | Chave de criptografia de tokens JWT do NextAuth | `devquest-prod-secret-32-chars-random-string` |
| **`NEXTAUTH_URL`** | URL base do ambiente (local ou produção) | `https://devquest-zeta.vercel.app` (em prod) ou `http://localhost:3000` (local) |
| **`NEXT_PUBLIC_APP_URL`** | URL pública exposta ao cliente para montagem de links absolutos | `https://devquest-zeta.vercel.app` |
| **`AUTH_GITHUB_ID`** | Client ID do aplicativo OAuth no GitHub | `Ov23li...` |
| **`AUTH_GITHUB_SECRET`** | Client Secret do aplicativo OAuth no GitHub | `4a9f...` |
| **`AUTH_GOOGLE_ID`** | Client ID do Google Cloud Console | `102938...apps.googleusercontent.com` |
| **`AUTH_GOOGLE_SECRET`** | Client Secret do Google Cloud Console | `GOCSPX-...` |

---

## ⚠️ Cuidados Importantes na Vercel

> [!warning] Atenção à Variável NEXT_PUBLIC_APP_URL
> Se `NEXT_PUBLIC_APP_URL` estiver configurada como `http://localhost:3000` no painel da Vercel, o frontend tentará fazer requisições para a máquina local do usuário final, causando erros de `Failed to load resource: net::ERR_CONNECTION_REFUSED` ou 500. Garanta que na Vercel esteja configurado o domínio oficial `https://devquest-zeta.vercel.app`.
