# 💻 Guia de Comandos & Scripts NPM

> [!abstract] Operações do Desenvolvedor
> Lista de todos os comandos configurados no `package.json` para desenvolvimento, teste, migração de banco e build.

---

## 📜 Comandos Disponíveis

| Comando | O que executa | Quando usar |
| :--- | :--- | :--- |
| **`npm run dev`** | `next dev` | Inicia o servidor local de desenvolvimento na porta `3000` com Turbopack. |
| **`npm run build`** | `next build` | Compila o projeto para produção e gera as páginas estáticas (SSG) e rotas dinâmicas. |
| **`npm run start`** | `next start` | Sobe o servidor Node.js servindo o build de produção compilado. |
| **`npm run lint`** | `next lint` | Executa o ESLint para detectar más práticas e erros no código. |
| **`npm test`** | `vitest run` | Executa a suíte completa de testes automatizados (59 testes). |
| **`npm run test:watch`** | `vitest` | Executa testes em modo vigia enquanto você altera arquivos. |
| **`npm run test:e2e`** | `playwright test` | Executa testes ponta a ponta no navegador Chromium/Firefox/WebKit. |
| **`npm run db:push`** | `drizzle-kit push` | Aplica o schema Drizzle (`schema.ts`) diretamente no Neon Postgres. |
| **`npm run db:seed`** | `tsx --env-file=.env src/lib/db/seed.ts` | Popula o banco com dados de trilhas, desafios e projetos iniciais. |
