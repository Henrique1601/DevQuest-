# DevQuest Pro Instructions
- Siga estritamente todas as diretrizes e a matriz de skills descritas em @AGENTS.md.
- **Antes de qualquer implementação**: Acione obrigatoriamente as skills pertinentes da matriz (ex: `modern-web-guidance`, `neon-postgres`, `obsidian-vault`, `find-docs`, `webapp-testing`, etc.).
- **Análise & Qualidade**: Inspecione o código antes para prevenir falhas e cace ativamente bugs pós-implementação.
- **Testes & Build**: Execute sempre `npm run test`, `npx playwright test` e `npm run build` antes de qualquer entrega.
- **Documentação Contínua**: Mantenha sempre atualizados `walkthrough.md`, `implementation_plan.md` e o cofre Obsidian (`Cerebro_Dev_quest/`).
- **Git & Commits**: Utilize convenções claras via `caveman-commit` (Conventional Commits ≤50 chars).
